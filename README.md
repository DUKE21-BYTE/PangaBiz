- **`TERMS.md`**: Merchant Terms of Service.

### GitHub Pages Setup
1. In repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Branch: `main`, Folder: `/ (root)`.
4. Click **Save**.
